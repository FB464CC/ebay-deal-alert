Checkpoint 5 - implementation and single-bypass proof
-----------------------------------------------------
- Added only top-level config key `GOLF_MODERN_SET_MAX_LANDED_PRICE: 200`, read
  through the same `_CONFIG.get(..., 200)` fail-safe pattern as the surrounding
  golf settings. No saved-search object or existing config value changed.
- `golf_modern_set_absolute_price_path_applies()` is intentionally narrower
  than the final golf gate. It requires a real golf AI check, finite landed
  price <=$200, known shipping, a usable AI appraisal, affirmative modern-model
  evidence, and the existing full/iron-set helper. It then repeats the existing
  low-confidence, handedness, brand-claim, counterfeit, and damage decisions.
- In `is_blocked_by_steal_quality_gate()`, blocked-brand and $300 hard-cap checks
  run before the relative decision. A missing AI price still blocks. The new
  helper is consulted only after computing the old `landed > resale` / less-
  than-50%-under failure; only that failure may be excused. The existing
  low-confidence, playability, RH, brand-claim, counterfeit, and damage checks
  then run again, and `golf_full_set_only_reason()` runs again at the delivery
  call site. The path marker is assigned only after all those checks pass.
  Therefore the one bypass is exactly the relative price-vs-AI-estimate bar;
  no shape, brand, era, junk/blade, AI-vetting, handedness, confidence,
  authenticity, condition, or hard-price gate is bypassed.
- eBay detail shipping refresh is scoped to golf-equipment so apparel, watch,
  poker, and other relative-price paths cannot change as a side effect. The
  existing golf relative threshold itself is unchanged; it simply receives an
  honest landed number when eBay provides one.
- Absolute-path alerts carry `GOOD PRICE: modern set under $200 landed
  (absolute ceiling, not the steal test)`. The existing club-run, RH evidence,
  AI ID, verify, and ending-soon lines remain intact; old relative-path alerts
  retain their existing rating/steal presentation.
- Added a code-owned official Browse-API `golf irons` auction lane in category
  115280. It reuses focused id `golf-irons` without changing that saved-search
  entry, runs every poll rather than in rotation, and alone uses 30/30-minute
  contested/uncontested windows. Official-lane rows qualify for the existing
  reserved auction AI call. The old scraped Rogue was auction-prioritized but,
  by design, scrape rows could not use that reservation; it happened to obtain
  a normal shared AI slot. No rule allowing a non-AI-vetted alert changed.
