2026-10-18 - implementation and verification
----------------------------------------------
- Added vinted_fast.py: a bounded 70-minute, 22-search round-robin lane with a
  hardcoded four-second request floor, 24-row newest-first pages, durable
  per-search high-water markers, its own seen DB/log, main-seen-DB checks,
  first-run baselining, compact minute summaries, 401 session refresh, and
  60/120/240/480/900-second 403/429 backoff (capped at 15 minutes and reset by
  a successful catalog response). It ignores FOCUS_SEARCH_IDS by design.
- The pipeline is ordered cheap saved-search/scoring gates -> Jev -> the
  existing category-aware photo check -> the existing steal-quality gate ->
  the existing final sanity check -> send_alert. All finalized lane outcomes
  use the compatible alerts-log schema in vinted_fast_log.jsonl and the lane
  seen DB. A first observation only records a baseline, preventing deployment
  from treating the existing catalog as new inventory.
- NO_AI_BUDGET policy: when the 40-call lane cap or an existing provider/monthly
  guard refuses a photo result, the row is logged with NO_AI_BUDGET and marked
  seen. It is not retried next run. This deliberately protects the next run's
  fresh listings from a growing stale backlog and makes every deferral visible.
- Added direct TypeSafe image Jev with up to three resized baseline-JPEG assets,
  reference strings in state, the required danger-zone header, category-specific
  negative-only questions, and a <=0.05 skip threshold. Invalid/too-narrow
  images are skipped; both dimensions of every submitted image are 280..1568.
  Direct errors fail open. With no TYPESAFE_API_KEY, the existing OpenRouter
  decision endpoint receives title/description only and also fails open.
- Added golf image Jev in configurable off/shadow/skip modes, defaulting to
  shadow. Its probability is retained as jev_image_iron_set on the normal alert
  log row; shadow never changes the golf decision.
- The main poll now excludes Vinted only when VINTED_FAST_ENABLED is true, so
  its existing golf focus and all other marketplace behavior remain unchanged.
- Added .github/workflows/vinted-fast.yml (hourly at :07, non-canceling
  vinted-fast concurrency, 80-minute timeout, matching Python/dependency and
  secret setup plus TYPESAFE_API_KEY). Only vinted_fast_seen.db,
  vinted_fast_state.json, and vinted_fast_log.jsonl are saved/pruned under a
  dedicated Actions-cache prefix. It also restores the latest main-poll seen
  cache read-only for cross-lane dedupe, but never saves or commits that file,
  so it does not conflict with poll.yml state.
- The existing paid-provider ledger mirror is redirected to the cached lane
  seen DB only for the lane process, so its unchanged monthly budget guard is
  durable across hourly runs even though this workflow never commits poll
  state. The original engine DB path is restored when the bounded run exits.
- Live discovery: Vinted retired /api/v2/catalog/items. The anonymous adapter
  now uses https://api.vinted.com/svc-catalogue/items with the homepage-issued
  anon/access token headers (no account/login), current relative item URLs,
  full_size_url photos, and item_box size/condition fields. The same public
  item-page request used for seller descriptions now exposes gallery preload
  images so Jev can see up to three listing photos.

REQUEST AND COST BOUNDS
-----------------------
- The four-second floor permits at most 15 paced Vinted catalog/item-page
  requests per minute: 900/hour or 1,050 in a full 70-minute run. With no new
  candidates, 22 searches are revisited about every 88 seconds (~41 times/hour
  each). A title-relevant new item can consume one paced public-page slot, so it
  displaces rather than adds to that 900/hour Vinted request ceiling. Image-CDN
  downloads and TypeSafe/AI provider calls are separate from this API/page rate.
- At most 40 real photo checks are attempted per lane run. With the configured
  paid-provider reservation bounds, the worst local paid-AI reservation is
  40 x $0.01 vision plus up to 40 x $0.002 final text sanity = $0.48/run. The
  unchanged $10 monthly ledger remains the harder aggregate cap. TypeSafe/OpenRouter
  Jev provider billing is external to that local ledger.
