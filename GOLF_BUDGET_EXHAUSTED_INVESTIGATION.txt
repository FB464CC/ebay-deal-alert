Checkpoint 4 - Task 3 OfferUp enablement report (no change made)
- Required config field: append `"offerup"` to each target saved search's
  existing `platforms` array. OfferUp is already in top-level
  MARKETPLACES_ENABLED and registered as a batch adapter. The current focus is
  23 golf searches, all with `platforms=["shopgoodwill","facebook"]`; enabling
  every focus search would therefore be 23 saved-search field edits. None was
  made.
- Runtime cost: OfferUp's batch-shaped adapter actually performs one sequential
  public HTML request per query. Enabling all 23 focus searches schedules up to
  23 OfferUp search requests/run, paced at a minimum 0.50 seconds and bounded
  by the shared 90-second marketplace deadline (15-second maximum per started
  request, partial coverage returned at deadline). Twenty-three starts imply at
  least about 11 seconds of pacing gaps plus network time. Each genuinely new
  result whose search card lacks description can also cause one OfferUp detail
  page request during PASS 1 before price/relevance gates.
- ShopGoodwill/eBay discovery capacity: no direct reduction. OfferUp runs in
  its own daemon batch thread; ShopGoodwill keeps its own two-worker queue and
  its same 23 focused requests, while official eBay keeps its independent
  13-fast + 3-slow per-run rotation and the scrape lane is unchanged. The only
  shared boundaries are wall-clock/run time and downstream review: any OfferUp
  golf candidates join the same 12-candidate shared AI window and can displace
  lower-priority eBay/ShopGoodwill golf candidates there.
- Local-pickup radius: none is configured or enforced. The adapter requests
  `https://offerup.com/search?q=<query>` with no ZIP, coordinates, location, or
  radius; it parses but discards OfferUp's `locationName`. Consequently the
  effective radius is undefined (whatever default/IP-personalized feed OfferUp
  returns), not an owner-local mileage radius. It also carries no distance or
  shipping cost into landed-price math. Enabling as-is would add OfferUp
  discovery, but it would not guarantee that a local-pickup-only club set is
  within driving distance.
